# StepIssueSeverityEnum

Blocking severity of the issue. `error` (default when omitted) blocks save; `warning` is a non-blocking notice.

## Example Usage

```csharp
using Novu.Models.Components;

var value = StepIssueSeverityEnum.Error;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `Error`   | error     |
| `Warning` | warning   |
